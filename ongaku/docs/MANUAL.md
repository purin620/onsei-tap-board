# 先生用 操作マニュアル

## 1. 学習の流れ

1. アプリを開くと「開始画面」が出ます。**児童**を選び、モードと曲数を確認します。
2. 「**学習スタート**」を押す（音を出せる状態になり、学習記録が始まります）。
3. 大きなボタンの画面になります。児童がスイッチを押すと音楽が流れます。
4. 終わるときは、右下の**歯車を1.5秒長押し** →「**学習をおわる**」。
5. 「学習のふりかえり」で観察記録の数とメモを入れて「記録を保存」。

> 学習中に歯車を短くさわっても設定は開きません。スイッチの入力でも開きません。

## 2. 児童用画面

| 状態 | ボタン |
|---|---|
| 止まっている | **緑**・▶・「きく」 |
| 流れている | **オレンジ**・■・「とめる」 |
| 2スイッチ | 左＝スイッチ1、右＝スイッチ2（位置は変わりません） |

色・大きさ・文字の表示／非表示・曲名の表示は「画面」タブで変えられます。点滅やアニメーション、効果音は使っていません。

## 3. 学習モード（「学習モード」タブ）

| モード | 動き | 主な設定 |
|---|---|---|
| A 再生・停止 | 1回押すと流れる、もう1回で止まる | もう一度押したとき「止めたところから／はじめから」 |
| B 一定時間再生 | 1回押すと決めた秒数（3・5・10・15・30・60秒・任意）流れて自動で止まる | 再生中に押したとき「反応しない／止める／数え直す」、次に押したとき「つづきから／開始位置から／つぎの曲」 |
| C 曲送り | 1回押すと次の曲が流れる（最初の1回は1曲目）。最後の次は最初の曲 | 決めた時間で止める |
| D 2スイッチ | スイッチ1・2にそれぞれ機能を割り当て（はじめは 1＝きく・とめる、2＝つぎのきょく） | 機能：きく・とめる／すこしきく／つぎのきょく／まえのきょく／押している間だけ／とめる |
| E 押している間だけ再生 | 押している間だけ流れ、離すと止まる | もう一度押したときの位置 |

共通の設定：使うプレイリスト、順番／ランダム、曲が最後まで流れたら「止まる／くり返す／つぎの曲へ」、全体の音量。

### 段階的な使い方の例（仮の案）

実態に合わせて先生が判断してください。

1. **モードB（10〜15秒）・再生中は反応しない**：押す→音楽、の結び付きを短い時間で何度も経験する。
2. **モードB（5秒）**：時間を短くして、自分から押す回数を増やす。
3. **モードA**：自分で「流す」「止める」を選ぶ。
4. **モードC／D**：曲を変える＝「ちがうものを選ぶ」経験へ（将来のAACや意思表示へのつながり）。

## 4. 音楽・プレイリスト（「音楽」タブ）

- 曲の追加：[SETUP.md](SETUP.md) の「2. 音楽ファイルを追加する」。
- プレイリストは複数作れます（例：「Aさんのすきな曲」「朝の会」）。
- 曲順は ↑↓ で変更。「はずす」はプレイリストから外すだけで、曲は消えません。
- 曲を完全に消すときは「編集」→「この曲を削除」。
- 「保存場所」に、使っている容量と「データ保護」の状態が表示されます。

## 5. スイッチ（「スイッチ」タブ）

- **スイッチ入力テスト**：押したキー・スイッチ1/2・押した／離したが表示されます。テスト中は音楽は鳴りません。
- **キーの割り当て**：「スイッチ1にキーを登録」→ スイッチを押す。
- **使う入力**：キーボード入力・画面タッチ・メディアキーをそれぞれ使う／使わない。
- **誤入力の防止**：次の入力を受け付けるまでの時間（なし〜3秒）。
- **止めるときの音の消え方**：すぐ／0.5秒／1秒。

## 6. 学習記録（「学習記録」タブ）

### 自動で記録されること

実施日、開始・終了時刻、学習時間、スイッチ入力回数、有効な操作回数、再生・停止・自動停止・曲送りの回数、再生した曲、学習モード、すべての操作の時刻。

- 「有効な操作」＝音楽が流れる・止まる・変わるなど、変化が起きた入力。
- 「無効」＝誤入力防止の時間内、モードBの再生中など、変化が起きなかった入力（理由も記録）。

### 先生が記録すること（観察記録）

自発的に押した／言葉掛けで押した／身体的な支援で押した／偶然触れた／手を伸ばそうとした／笑顔が見られた／停止時に反応／その他の気付き、とメモ。

**自発的な操作かどうかを、アプリは判定しません。先生が見て記録します。**

記録の方法：
- 学習中に歯車を長押し →「学習記録」タブの「いまの学習」で ＋／−。
- 「画面」タブで「観察記録ボタン」を表示すると、学習画面の上で数えられます（児童がさわりやすい場合は表示しない）。
- 学習の終わりの「ふりかえり」画面。
- 過去の記録も「くわしく」から直せます。

### 見る・出力する

- 日ごとの一覧、「スイッチ入力回数」と「自発的に押した回数」のグラフ。
- **記録一覧CSV**（1回の学習ごとに1行）と**操作ログCSV**（操作1つごとに1行）。Excelで開けます。iPadでは「ファイル」アプリの「ダウンロード」に保存されます。

## 7. データ・児童（「データ・児童」タブ）

- 児童は**イニシャルや呼び名**で登録してください（実名は使わない）。
- **バックアップ**：「音楽もふくめて保存」または「設定と記録だけ保存」。`.ongaku` ファイルが「ダウンロード」に入ります。月に1回程度、または曲を追加したあとにとっておくと安心です。
- **復元**：バックアップファイルを選ぶと、いまのデータを消してバックアップの内容にもどします。
- バックアップやCSVには児童の登録名と学習記録が入ります。**校内の個人情報の取り扱いの決まりに従って保管**し、外部のサービスに送らないでください。

## 8. 学習指導要領との関連（参考）

参照：特別支援学校小学部・中学部学習指導要領（平成29年4月告示）。岩手県教育委員会や本校の教育課程の定めがある場合はそちらを優先してください。

**第7章 自立活動**（区分と項目は「第2 内容」より）

| 区分 | 関連する項目 | この教材での場面 |
|---|---|---|
| 環境の把握 | (1) 保有する感覚の活用／(5) 認知や行動の手掛かりとなる概念の形成 | 音を手掛かりに、自分の動きと結果（音が流れる・止まる）の関係に気付く |
| 身体の動き | (1) 姿勢と運動・動作の基本的技能／(2) 姿勢保持と運動・動作の補助的手段の活用 | スイッチに向かって手を伸ばす、押す。スイッチの位置・種類の工夫 |
| コミュニケーション | (1) コミュニケーションの基礎的能力／(4) コミュニケーション手段の選択と活用 | 「もっと聞きたい」を自分の操作で表す。将来のAAC（拡大・代替コミュニケーション）へ |
| 心理的な安定 | (1) 情緒の安定 | 好きな音楽を自分で流す安心感・楽しさ |
| 人間関係の形成 | (1) 他者とのかかわりの基礎 | 音楽が止まったときに教師を見る、表情で伝える場面を教師が受け止める |

- **第1章 総則 第8節**「重複障害者等に関する教育課程の取扱い」：重複障害のある児童で、自立活動を主とした指導を行う場合の根拠になります。
- **第1章 総則**の、コンピュータや情報通信ネットワークなどの情報手段・教材教具の活用に関する規定：ICT（iPad・外部スイッチ）を障害の状態に応じて活用する根拠になります。
- 知的障害者である児童に対する教科の「音楽」（小学部1段階の鑑賞・音楽遊びに関する内容）と関連付けることもできます。該当する目標・内容の文言は学習指導要領で確認してください。

※ 項目番号・文言は、学校にある学習指導要領・解説（自立活動編）で必ず確認してください。

### 個別の指導計画への記入例（仮の案）

- **実態把握**：音楽を聴くと笑顔になる。興味のある場面では教師を目で追う。膝をたたく動き、物を握る動きがある。スイッチに向かって手を伸ばす学習をしている。
- **長期目標**：好きな音楽を聴くために、自分からスイッチを押して音楽を流す。
- **短期目標**：モードB（10秒）で、言葉掛けがあればスイッチに手を伸ばし、1回の学習で〇回以上押す。
- **具体的な手立て**：スイッチを手の届く位置（膝の近く・手を下ろした先など）に置く。手の過敏さに配慮し、表面の素材やさわる時間を調整する。音楽が止まったら少し待ち、自分から動くのを待つ。
- **評価の観点**：「自発的に押した」「言葉掛けで押した」「身体的な支援で押した」の回数の変化（記録一覧CSV・グラフ）、表情（笑顔・停止時の反応）。
