# 導入手順・音楽の追加・外部スイッチの設定

## 1. iPadで開く

1. iPadの **Safari** で次のURLを開きます。
   `https://purin620.github.io/onsei-tap-board/ongaku/`
2. 共有ボタン（□に↑のマーク）→「**ホーム画面に追加**」→「追加」。
3. ホーム画面にできた「おんがく」のアイコンから開きます。アドレスバーのない全画面で使えます。
4. 一度開くと、アプリの部品がiPadに保存され、**次からはインターネットがなくても開けます**。

### 大切な注意：音楽は「ホーム画面のアプリ」で追加する

iPadでは、Safariで開いたときと、ホーム画面から開いたときで、**保存場所が別々**になります。
Safariで追加した曲は、ホーム画面のアプリには出てきません。
**ホーム画面に追加してから、そのアプリで曲を追加**してください。

### 学校のiPadで使うとき

- 学校の管理（MDM）で「ホーム画面に追加」やSafariのWebサイトが制限されている場合があります。開けないときは、情報担当の先生や管理者に、このURLの許可を相談してください。
- オフライン機能は https のページでだけ動きます（上のURLは https です）。
- 「Safariの履歴とWebサイトデータを消去」を行うと、曲や記録も消えます。定期的にバックアップをとってください（→ [MANUAL.md](MANUAL.md) の「バックアップ」）。

## 1-2. Safariが使えないiPad（ロイロノートで開く）

学校の設定でSafariが使えない場合は、**ロイロノートの「Webカード」**で開きます。

1. 先生のロイロノートで「Web」→ アドレスに `https://purin620.github.io/onsei-tap-board/ongaku/` を入れて **Webカード**を作る。
2. そのカードを児童の端末に送る（または資料箱に入れておく）。
3. 児童の端末でWebカードを開き、拡大して使う。

ロイロノートの中で開いたときのちがい：

| | Safari・ホーム画面 | ロイロノートの中 |
|---|---|---|
| 再生・停止・外部スイッチ | 使える | 使える（見込み・実機未確認） |
| 曲・記録の保存 | 端末に保存 | ロイロノートの中に保存（見込み） |
| インターネットなしで使う | できる | **できない**（つながっているときに使う） |
| CSV・バックアップの保存 | 共有の画面 または ダウンロード | 保存できない場合あり →「画面に表示（コピー用）」を使う |
| 録音して追加 | できる | ロイロノートのマイクの許可しだい |

- 開始画面に「ロイロノートなどのアプリの中で開いています」と出ていれば、ロイロノートの中で動いています。
- **曲は、児童の端末のロイロノートの中で開いたアプリから追加**してください（保存場所が端末・アプリごとに別々のため）。お試し用の曲は、はじめて開いたときに自動で入ります。
- 外部スイッチを使うときは、一度アプリの画面（大きなボタンの外側でもよい）をタッチしてから押すと、キーが届きやすくなります。
- 学校のフィルタリングで `purin620.github.io` が開けない場合は、情報担当の先生に許可を相談してください。

## 2. 音楽ファイルを追加する

### お試し用の曲

はじめて開いたときに、**お試し用の曲が3曲**（きらきらぼし・メリーさんのひつじ・かえるのうた）入っています。
著作権の保護期間が終わった童謡のメロディーを、アプリがオルゴール風の音で作ったものです。曲を用意しなくても、すぐにスイッチの動作確認ができます。
いらなくなったら「音楽」タブの「編集」→「この曲を削除」で消せます。もう一度入れたいときは「♪ お試し用の曲を入れる」を押します。


使える形式：**MP3・M4A（DRMのないAAC）・WAV** など、iPadで再生できる音声ファイル。
※ YouTube Music や Apple Music でダウンロードした曲は、取り出せない（DRMで保護されている）ため使えません。
※ 著作権のルールを守り、先生が正しく用意した音源を使ってください。

### 手順

1. 音楽ファイルを iPad の「**ファイル**」アプリに入れておきます（例：AirDrop、USBメモリ、学校の共有フォルダ、iCloud Drive などから）。
2. おんがくスイッチを開き、「先生用の設定」→「**音楽**」タブ。
3. 「＋ 音楽ファイルを選ぶ（複数可）」→「ブラウズ」→ ファイルを選びます。右上の「選択」で**複数まとめて**選べます。
4. 追加された曲は、そのとき選んでいるプレイリストに入ります。

### 録音して追加する

「音楽」タブの「● 録音して追加」で、iPad／iPhoneのマイクで録音した音を、そのまま曲として登録できます。
先生の歌や楽器の演奏、学校で作った音楽などに使えます。

1. 「● 録音をはじめる」（はじめて使うときは、マイクの使用を「許可」）
2. 歌う・演奏する → 「■ 録音をとめる」
3. 再生して確かめる → 曲名を入れて「保存して追加」
4. はじめ・おわりの無音は、「編集」の開始位置・終了位置で切れます。

※ 音楽配信サービス（YouTube Music など）で流した曲を録音することは、各サービスの利用規約で禁止されています。
※ マイクが使えないときは、「設定」→「Safari」（またはアプリ）→「マイク」を「許可」にしてください。

### 曲の編集（曲名・サビだけ使う・音量）

「音楽」タブの曲の「**編集**」から：
- **曲名**を変える（児童の画面に表示されます）。
- **使う部分**：プレーヤーで流して、使いたいところで「いまの位置を開始にする」「いまの位置を終了にする」。
- **音量**：曲ごとに 0〜200% で調整。
- 「▶ この設定できく」で、学習のときと同じ鳴り方を確認できます。

## 3. 外部スイッチを使う

接続のしかたによって、設定がちがいます。**まず「スイッチ」タブの「スイッチ入力テスト」で、押したときに何が表示されるか確認**してください。

### 方法① キーボードとして認識されるスイッチインターフェース（おすすめ）

Bluetoothや有線で接続し、スイッチを押すと「スペース」や「エンター」などのキーとして届く機器です。

1. iPadの「設定」→「Bluetooth」で機器をペアリング（機器の説明書にしたがう）。
2. おんがくスイッチの「スイッチ」タブ →「スイッチ入力テスト」でスイッチを押す。
   - 「スペース → スイッチ1」などと表示されれば使えます。
   - 表示が出ない場合は、iPadの「スイッチコントロール」がオンになっていないか確認してください（オンだとキーがアプリに届きません）。
3. はじめの設定：**スペース・←・1 ＝ スイッチ1**、**エンター・→・2 ＝ スイッチ2**。
   ちがうキーが届く機器は「スイッチ1にキーを登録」を押してから、そのスイッチを押すと登録できます。
4. 1スイッチのモード（A・B・C・E）では、どのキーでもボタンを押したことになります（設定で変更可）。

この方法は、**反応がいちばん速く**、「押している間だけ再生（モードE）」にも対応します。

### 方法② iPadの「スイッチコントロール」を使う

iPadの「設定」→「アクセシビリティ」→「スイッチコントロール」でスイッチを登録して使う方法です。
この場合、スイッチの入力はiPadが使うため、アプリにはキーとして届きません。次のどちらかで操作します。

- **項目を選択**：スキャンのカーソルが大きなボタンに来たときに押すと、ボタンを1回押したことになります。画面のボタンが1つ（1スイッチのモード）なら選びやすくなります。
- **レシピ（おすすめ）**：「スイッチコントロール」→「レシピ」→「新規レシピを作成」→ スイッチに「**カスタムジェスチャ**」で画面中央をタップする動作を割り当てる → 学習の前にそのレシピを起動。スイッチを押すと、画面中央のボタンがタップされます。
  2スイッチのときは、左右のボタンの位置をそれぞれタップするジェスチャにします。

※ スイッチコントロールでは「押している間」が伝わらないため、モードEは押すたびに再生・停止になります。
※ 歯車（設定）は1.5秒の長押しでしか開かないので、スイッチコントロールで誤って開くことはありません。

### 方法③ 画面に直接さわる

大きなボタンをタッチしても動きます。指を置いている間は1回として数えます。

### アクセスガイドとの併用（おすすめ）

「設定」→「アクセシビリティ」→「アクセスガイド」をオンにして、アプリを開いた状態でトップボタン（ホームボタン）を3回押すと、
アプリから出られなくしたり、画面の一部（右下の歯車など）をさわれなくしたりできます。

### 誤入力の防止

「スイッチ」タブの「誤入力の防止」で、1回反応したあと次の入力を受け付けるまでの時間を選べます（はじめは0.5秒）。
長押ししても、離すまでは1回として扱います。

## 4. 音が出ないとき

- iPadの音量ボタンで音量を上げる／消音（サイレント）モードを解除する。
- 学習の前に、先生が「**学習スタート**」を押す（iPadは、画面にふれるまで音を出さない決まりがあるため）。
- 長い時間ほかのアプリを使ったあとは、一度「先生用の設定」を開いて閉じるか、スイッチをもう一度押す。
- 曲の「試聴」で鳴らない場合は、ファイルの形式（DRM付きの曲でないか）を確認する。
