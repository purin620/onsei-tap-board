# 音声タップボード

特別支援学校向け、発語のない児童がタップだけで場面の進行（朝の会・帰りの会など）をできる読み上げボードです。

- `index.html` を開くだけで動きます（ビルド不要の単一HTMLファイル）。
- 画面には現在の項目カードが1枚だけ表示され、タップすると読み上げてから次のカードに自動で切り替わります。
- 右上の⚙（歯車）から、各カードの名前・読みあげる言葉・色・絵・順番を編集できます（先生用）。
- 声の種類・読み上げの速さを選べます（⚙→「おんせい」）。
- 朝の会・帰りの会など、場面ごとに複数のボードを作って保存できます（⚙→「ボード」）。
- Web Speech API（`speechSynthesis`）を使って日本語で読み上げます。端末に日本語音声がインストールされている必要があります。

## 使い方

`index.html` をブラウザ（タブレット推奨）で開くだけです。GitHub Pages で公開すれば、そのままタブレットのブラウザからアクセスできます。

## GitHub Pages で公開する場合

1. このリポジトリの Settings → Pages を開く
2. Source を `Deploy from a branch`、Branch を `main` / `/(root)` に設定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` でアクセスできるようになります

## ことばでつたえよう（五十音表の読み上げ）

`kotoba/index.html` は、紙の五十音表と同じ並び（右から あ行）の文字をタップすると1文字ずつ読み上げるページです。「あいう」「がぎぐ」「きゃ・っ」の3つの表を下のタブで切り替えます。右下の⚙を1.5秒長押しすると先生用の設定（速さ・声・「よむ」ボタン）が開きます。

公開URL: `https://purin620.github.io/onsei-tap-board/kotoba/`
