# Codexへの依頼文（そのまま貼ってOK）

このフォルダには、すでに動作するスマホ向け「ふくろで つくりおき」アプリがあります。
**最初から作り直さず**、既存の `index.html` を利用してください。

お願いしたいこと：
1. `index.html` を確認して、iPhone Safariでボタン・チェック・画面切替が正常に動作するかテストしてください。
2. GitHub Pagesまたは利用可能な静的サイトホスティングでHTTPS公開する手順を用意してください（必要なら設定ファイルを追加）。公開操作にアカウント連携や権限が必要な場合はユーザーに確認してください。
3. 11種類の「切るまえ→切ったあと」イラスト、食材別の3ステップ説明、14袋への分量振り分けを保持してください。
4. 14袋と献立の計算が一致することをテストしてください。月〜日の野菜袋1〜7と肉・魚袋8〜14です。
5. 火木土のおかずは仕込み日に加熱調理し冷凍、月水金日の鍋は生の食材を別袋で冷凍する区別を保ってください。
6. 保存状態がブラウザのlocalStorageに残るようにしてください。

最優先は、**実際に押せるiPhoneのWebアプリとして公開すること**です。ChatGPTのHTMLプレビューはJavaScriptを実行できない場合があります。
