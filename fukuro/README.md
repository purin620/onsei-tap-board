# ふくろで つくりおき — イラスト版

## 使い方
- `index.html` はイラスト11種類を内蔵した単独ファイルです。PCのChrome/Safariで開くか、GitHub Pages等で公開すると動きます。
- iPhone版ChatGPTアプリや「ファイル」の簡易プレビューではJavaScriptのボタンが動かない場合があります。Safariでアクセスできる **HTTPSのWebサイト** として公開するのが確実です。
- `illustrations` フォルダには後から差し替え・編集できるSVG画像を収録しています。
- データはブラウザのlocalStorageに保存され、デバイス間同期はありません。

## アプリの流れ
1. 袋①〜⑭に曜日・野菜/肉/魚と番号を書く。
2. 食材ごとの「切るまえ→切ったあと」の画像と3つの手順を見る。
3. 指定の袋に量って入れたらチェックする。
4. 鍋4日分の袋は生のまま冷凍。火木土のおかずは仕分け後その日に調理し、完成品を冷凍。
5. 「袋を確認」「料理する」「買い物」も利用可能。

## Codex に追加で依頼する例
「このサイトをGitHub Pagesに公開できるよう設定し、iPhoneのSafariでボタンが確実に動作するか確認してください。買い物リストや献立を編集して分量を再計算する機能も追加してください。」

## 安全について
妊娠中の方も食べるため、生肉・魚と野菜の交差汚染に注意し、中心温度75℃で1分以上を目安に十分に加熱してください。加熱済み料理は速やかに冷却・冷凍、食べる日に十分に再加熱します。

## HTTPS公開手順（現在は未公開）
1. 自分のGitHubアカウントでリポジトリを作成します。公開リポジトリの場合、アップロードしたソースも公開されます。
2. このフォルダの `index.html`、`manifest.webmanifest`、`app-icon.png`、`illustrations` をリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deploymentで「Deploy from a branch」、ブランチ `main`、フォルダ `/(root)` を選びSaveします。
4. Pagesに表示される `https://…github.io/…/` をiPhoneのSafariで開きます。ZIPやHTMLのプレビュー用URLではありません。
5. 白菜の①をチェック → 次へ（しめじ）→ 前へ → Safariの再読み込みを行い、チェックの保持を確認します。他タブ・買い物も確認してください。

公開先が変わると保存領域も変わります。プライベートブラウズ終了やWebサイトデータ削除で記録が消える場合があります。保存に失敗した場合は画面に案内が出ます。オフライン動作は保証しません。

## 開発時の受け入れテスト
PythonとNode.js、Playwrightおよび対応ブラウザがある環境で実行します。

```sh
python -m http.server 8000
# 別ターミナルで実行
node tests/acceptance.cjs
```

WebKitとChromiumで375px幅・タッチ操作、11図、31チェック、14袋の総量、タブ、曜日、保存復元、リセット確認、不正保存値からの起動を検証します。WebKitの自動テストはiPhone Safari実機での確認とは異なります。
