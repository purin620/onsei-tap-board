## テストの再実行

Node.js、Python、Playwrightが必要です。アプリ自体にはこれらのインストールは不要です。

```sh
# プロジェクトのフォルダで起動
python -m http.server 8000

# 別ターミナルで、テスト用の依存を準備
npm install --no-save playwright
npx playwright install chromium webkit
# Linuxで不足ライブラリがある場合、権限を確認して依存を準備
# npx playwright install-deps chromium webkit

# WebKitとChromiumを実行
node tests/acceptance.cjs

# WebKitが使えない場合のChromiumのみの実行
CHROMIUM_ONLY=1 node tests/acceptance.cjs
```

`PLAYWRIGHT_MODULE` 環境変数でPlaywrightモジュールの場所を指定できます。テストの対象URLは `http://127.0.0.1:8000` です。テストはそのURLの保存領域をリセットするため、実データを入れたサイトへ向けないでください。

## 維持する仕様・安全情報

- 食材ごとに全部切り、番号袋へ指定gを分ける導線。曜日ごとに切り直す導線にしない。
- 11図、14袋の対応、31割当、元の味付けを維持。
- 月水金日は生材料を野菜と肉魚の別袋で冷凍。火木土は仕込み日に加熱調理し、完成品を小分け・急冷・冷凍して食べる日に十分再加熱。
- 野菜を先に、生肉魚を最後に扱う。交差汚染防止、生肉魚を洗わない、中心75℃で1分以上の目安と温度計確認を維持。
- 袋ごと煮沸・電子レンジ加熱を勧めない。
- 全リセットには確認が必要。既存の保存キーを無断で変更しない。
